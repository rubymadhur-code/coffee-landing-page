# ☕ Coffee Landing Page

A modern, responsive, and interactive Coffee Landing Page built using **HTML, CSS, and JavaScript**. This project is perfect for beginners who want to learn frontend development by building a real-world website from scratch.


## ✨ Features

- ✅ Modern Landing Page UI
- ✅ Fully Responsive Design
- ✅ Mobile Navigation Menu
- ✅ Sticky Glass Navbar
- ✅ Scroll Reveal Animations
- ✅ Animated Counter
- ✅ Dark Mode with Local Storage
- ✅ Typewriter Effect
- ✅ Smooth Scrolling
- ✅ Clean & Organized Code
- ✅ Beginner Friendly

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
